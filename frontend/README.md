# Blombrain Frontend

Svelte 5 + TypeScript + Tailwind CSS v4 frontend for Blombrain.

## Development

```bash
npm install
npm run dev
```

The development server runs on `http://localhost:5173` and proxies `/api` requests to the Blombrain backend on `http://localhost:4300`.

## Type Checking & Production Build

```bash
npm run check
npm run build
```
